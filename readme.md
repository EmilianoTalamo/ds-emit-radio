## Prerequisites

Install yt-dlp on your system:

**Linux/macOS:**
```bash
pip3 install yt-dlp
# or using homebrew on macOS
brew install yt-dlp
```

**Windows:**
```bash
pip install yt-dlp
# or download from https://github.com/yt-dlp/yt-dlp/releases
```
